# design-only

For a tool that has no documentation reader or test footer, such as a GNOME Shell
extension. Only the shared visual and interaction rules apply.

- Applies `design-only` and the chosen quality profile.
- `BASIC-DESIGN-01`, `02` and `04` apply. `BASIC-DESIGN-03` is a review rule.
- Reader, footer, links, dates and web-server rules are listed as deviations in
  `basics.json` with a reason.
